# Domina Habermas - Netlify

Instrucciones:
1. Entra a Netlify.
2. Elige "Add new site" > "Deploy manually".
3. Arrastra este ZIP completo o la carpeta descomprimida.
4. Netlify detectará el archivo index.html en la raíz.

Contenido:
- Resumen profundo solo de Habermas.
- Glosario de conceptos.
- Mapa mental.
- 15 preguntas de desarrollo.
- Respuestas modelo al final.
- Autoevaluación con puntaje de 0 a 60.
- Conversión automática a nota chilena de 1,0 a 7,0.

Fuente base:
“La concepción de espacio público antes y después del cambio de paradigma: desobediencia civil y racionalidad en el segundo Habermas”.
